CardScan AI v3.2 — complete GitHub Pages upload

Upload the FOUR app files in this folder to the ROOT of your GitHub cardscan-ai repository:
- index.html
- manifest.webmanifest
- sw.js
- icon.svg

Do not upload the enclosing folder itself if that would put index.html inside a subfolder.
GitHub Pages should be configured to deploy from: main / (root).

If replacing an older version, remove/replace the old app files with these versions, then allow GitHub Pages a few minutes to redeploy. If Safari still shows an old version, close the CardScan AI tab/app and reopen the site.
