CardScan AI v3.1.2
===================
Built from v3.1.1.

Normal Recognize Card is unchanged.

New:
- Optional "Try Enhanced / Dark Card" button.
- Creates a grayscale, stronger-contrast preprocessing pass locally on the iPhone.
- Automatically inverts only when the source image is genuinely dark.
- Runs the same v3.1.1 OCR/parser after enhancement.
- Intended for difficult dark cards such as the GRC Industrial example.
- No cloud service or API key.
- Existing contact storage key remains cardscan_contacts.

Use normal Recognize Card first. Use Enhanced only when normal recognition is clearly poor.
Export a Backup before clearing Safari website data.
