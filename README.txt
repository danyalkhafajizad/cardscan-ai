CardScan AI v3.1.5

Built from v3.1.4 Photos.

New:
- Saved contacts now have separate Edit and Add Photos buttons.
- Add Photos opens the iPhone camera/photo picker directly; no need to enter Edit first.
- Multiple photos can be selected/attached.
- Edit remains dedicated to changing contact information.
- Existing contact/photo storage remains compatible.
- OCR and Enhanced/Dark Card recognition are unchanged.

Important iPhone note:
Safari and an installed Home Screen web app can keep separate local website-storage containers on iOS. CardScan remains local/offline, so use the Home Screen icon as the primary database. Export a Backup before clearing Safari/site data.
